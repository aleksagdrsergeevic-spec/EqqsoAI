# EqqsoAI

Магазин доступа к моделям и OpenAI-совместимый API в одном сервисе: лендинг,
личный кабинет с балансом и `/v1` по одному ключу. Тёмно-фиолетовый интерфейс,
мобильная вёрстка по умолчанию и поддержка Telegram Web App.

```
Браузер ──> лендинг + кабинет ──┐
Агент ──sk-ключ──> /v1 ─────────┴──> Groq / Cerebras / OpenRouter / Gemini
```

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать хотя бы один ключ провайдера
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Открыть `http://localhost:8000` — лендинг, `http://localhost:8000/health` — статус.

Первый ключ оператора (не тарифицируется):

```bash
python scripts/create_key.py "мой ноутбук"
```

Коды доступа для покупателей:

```bash
python scripts/create_code.py 50000            # код на 50 000 TKN
python scripts/create_code.py 50000 --count 5  # пять кодов
```

## Как устроена оплата

Единица — **TKN**. У каждой модели есть коэффициент: это цена 1000 токенов.
Запрос на 2000 токенов у модели ×5 стоит 10 TKN. Токены, прочитанные из кеша,
считаются за половину.

- Баланс пополняется кодом вида `WN-XXXXXXXX` в кабинете. Код одноразовый.
- Новому аккаунту начисляется пробный баланс `WELCOME_TKN` (по умолчанию
  10 000 TKN, `0` выключает) — чтобы человек мог попробовать до оплаты.
- Ушёл в ноль — API отвечает `402` с просьбой активировать код.
- Списанное видно в кабинете: сумма, график за 14 дней, разбивка по моделям,
  таблица последних 100 запросов.

Цена токена в рублях и канал продаж — ваши: код создаёт скрипт, а кто и за
сколько его продаёт, шлюз не знает и не проверяет.

## Кабинет

- Регистрация: логин 3–64 символа, пароль от 8. Без почты и подтверждений.
- Сессия — HttpOnly cookie на 30 дней.
- Ключи: до 5 на аккаунт, создаются и отзываются в кабинете.
- Вкладки: `Обзор` (баланс, подключение, активация, расход), `Модели`,
  `История` (статистика, график, операции).

## Провайдеры

Ключи — только в `.env` (или в переменных окружения контейнера):

| Провайдер | Переменная | Бесплатный тир |
|---|---|---|
| Groq | `GROQ_API_KEY` | быстрый, щедрый |
| Cerebras | `CEREBRAS_API_KEY` | быстрый |
| OpenRouter | `OPENROUTER_API_KEY` | модели `:free` |
| Gemini | `GEMINI_API_KEY` | `gemini-2.5-flash` |
| Mistral | `MISTRAL_API_KEY` | free tier |
| Anthropic | `ANTHROPIC_API_KEY` | нет, платный |

Все, кроме Anthropic, говорят на OpenAI-протоколе — для них шлюз только
подменяет имя модели. Anthropic подключается через свой `/v1/messages`, шлюз
переводит запрос и ответ на лету, поэтому `claude-*` работают обычным
OpenAI-запросом.

## Telegram

Сайт уже готов быть Web App: он подключает `telegram-web-app.js`, вызывает
`ready()` и `expand()`, красит шапку в фон сайта и показывает системную кнопку
«Назад» в кабинете.

Канал и поддержка: https://t.me/EqqsoAiBot

Чтобы открыть сайт из бота:

1. Опубликуйте сайт на постоянном адресе (**Go Live** в Project Details) —
   Web App должен открываться по https, превью для этого не годится.
2. В `@BotFather` → `/newapp` (или `/mybots` → бот → *Bot Settings* →
   *Menu Button*) укажите этот URL.
3. Там же можно поставить кнопку меню: `/setmenubutton` → выбрать бота →
   вставить URL → задать подпись, например «Открыть EqqsoAI».

Кнопка «В поддержку» в шапке и футере ведёт на тот же
`https://t.me/EqqsoAiBot`.

## Лимиты и логи

- `RATE_LIMIT_RPM` — потолок запросов в минуту на клиентский ключ, по
  умолчанию 600. Это защита от зацикленного агента, который за пару минут
  выест дневную квоту бесплатного тира: `0` выключает лимит.
- Счётчик лимита хранится в памяти одного процесса; для нескольких процессов
  понадобится общий Redis-счётчик.
- Каждый запрос пишется в stdout: `POST /v1/chat/completions -> 200 (840ms)`,
  а внутри — модель, выбранный провайдер и задержка
  (`ok model=llama-3.3-70b provider=groq ms=612`). В контейнере это видно
  через `docker logs`, на хостинге — в его логах.

## Ключ оператора

Ключ из `scripts/create_key.py` (и всё, что лежит в `API_KEYS`) не тарифицируется
и не привязан к аккаунту: им пользуетесь вы сами. Ключи покупателей живут в базе
и создаются в кабинете.

## Подключение агента

**OpenAI-совместимые** (Cline, Roo, Continue, Open WebUI, любой SDK):

```
Base URL: http://localhost:8000/v1
API key:  sk-...
Model:    gpt-oss-120b
```

**Anthropic-совместимые** (Claude Code, Anthropic SDK):

```
ANTHROPIC_BASE_URL=http://localhost:8000
ANTHROPIC_AUTH_TOKEN=sk-...
```

Имена вроде `gpt-4o-mini`, `o3-mini` и неизвестные `claude-*` не отвергаются:
они идут на `DEFAULT_MODEL`. Несколько имён Claude (Sonnet, Haiku, Opus 4.5)
имеют собственные native Anthropic-маршруты, если задан `ANTHROPIC_API_KEY`;
если ключ отсутствует, эти маршруты не показываются в `/v1/models` и ответят
понятной ошибкой настройки. Имя модели для маршрута можно поменять в
`MODEL_ROUTES`.

## Эндпоинты

- `GET /` — лендинг и кабинет (один документ)
- `GET /health` — статус и какие провайдеры настроены
- `GET /v1/models` — модели, доступные с вашим ключом
- `POST /v1/chat/completions` — чат в формате OpenAI, `stream: true` есть
- `POST /v1/messages` — Anthropic Messages: tool use, картинки, стриминг
- `POST /v1/messages/count_tokens` — грубая оценка токенов
- `/api/*` — сессии, баланс, ключи, история (JSON)

## Модели и фолбэки

У каждой модели список `targets` — шлюз идёт по нему сверху вниз, пока кто-то
не ответит:

```python
"llama-3.3-70b": {
    "targets": [
        {"provider": "groq", "model": "llama-3.3-70b-versatile"},
        {"provider": "cerebras", "model": "llama-3.3-70b"},
        {"provider": "openrouter", "model": "meta-llama/llama-3.3-70b-instruct:free"},
    ],
    "context_length": 128000,
    "family": "Llama",
    "label": "Универсальные задачи",
    "multiplier": 2.5,
},
```

Бесплатные тиры отвечают `429` регулярно — вместо ошибки агенту шлюз
переключается на следующий таргет (до 2 попыток на провайдера с бэкоффом).
Добавить модель — одна запись в `MODEL_ROUTES`, она сразу появится в каталоге.

Идентификаторы моделей у провайдеров меняются; если `/health` зелёный, а
запрос падает с `upstream_error`, сверь имя модели в консоли провайдера.

## Что шлюз чинит по дороге

- Параметры только-для-OpenAI (`store`, `metadata`, `service_tier`, ...)
  вырезаются, чтобы не словить 400 у апстрима.
- Ошибки отдаются в формате OpenAI (`{"error": {...}}`) и Anthropic
  (`{"type": "error", ...}`) — SDK показывают нормальный текст, а не сырое тело.
- `429`/`5xx` апстрима не долетают до агента, пока есть живой фолбэк.
- На стриме раз в 15 секунд уходит SSE-комментарий `: ping`, чтобы агент за
  прокси не отваливался по таймауту на медленном первом токене.

## Деплой

### VPS за пять минут

```bash
# 1. Docker (если ещё нет)
curl -fsSL https://get.docker.com | sh

# 2. Код
git clone https://github.com/<ваш-аккаунт>/EqqsoAI.git
cd EqqsoAI

# 3. Ключи провайдеров и свои настройки
cp .env.example .env
nano .env          # GROQ_API_KEY, GEMINI_API_KEY, MISTRAL_API_KEY, API_KEYS

# 4. Запуск
docker compose up -d --build
docker compose logs -f --tail=50

# 5. Проверка
curl localhost:8000/health
```

`docker-compose.yml` уже держит базу в томе `eqqsoai-data`, так что аккаунты и
балансы переживают перезапуск и пересборку.

### HTTPS и домен

Telegram Web App требует https. Проще всего Caddy — он сам выдаёт сертификат:

```
# /etc/caddy/Caddyfile
api.example.com {
    reverse_proxy 127.0.0.1:8000
}
```

`systemctl reload caddy`. Для nginx — обычный `proxy_pass http://127.0.0.1:8000`
с `proxy_buffering off;` на `/v1` (иначе стриминг буферизуется).

### Без Docker

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для продакшена оберните в systemd или gunicorn с `-k uvicorn.workers.UvicornWorker`.

### Коды доступа

```bash
docker compose exec eqqsoai python scripts/create_code.py 50000
```

Код печатается один раз — сохраните его, в базе он лежит уже использованным
или нет, но прочитать его снова из интерфейса нельзя.

## Ограничения

- Провайдеры бесплатные, значит данные у них. Не гоняй через шлюз то, что не
  готов отдать наружу.
- `/v1/messages/count_tokens` — оценка (символы / 4), а не реальный токенайзер.
- Лимит запросов считается в памяти процесса: несколько инстансов за
  балансировщиком получат каждый свой счётчик.
- Ключ аккаунта даёт доступ ко всем моделям каталога — отдельных разрешений на
  модель нет.
- Платежей внутри сайта нет: код выдаёт `scripts/create_code.py`, деньги вы
  принимаете сами, где вам удобно.
